# Changelog

## 0.2.0

- STL support (binary and ASCII).
- PLY support (ASCII and binary, vertex colours, point clouds).
- The up-axis button's choice is remembered per file type.

## 0.1.1

- `.vmdl`, `.obj` and `.gltf` now open in the viewer by default too (use **Text** in the toolbar to edit them).
- Release builds: each `v*` tag publishes the `.vsix` on GitHub Releases.

## 0.1.0

- 3D viewer for `.glb`/`.gltf`, `.obj`, `.dmx` (binary v1–9 and keyvalues2), `.vmdl` and `.vmdl_c`.
- **Models** sidebar listing every model in the workspace, with a filter.
